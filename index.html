Secure AI-Surveillance Using Post-Quantum LWE-Based Cryptography

Bridging Deep Learning Surveillance with Quantum-Resistant Security

Author: Syeda Yasmeen Date: May 2026 Framework: ResNet-50 + LWE Encryption
Abstract

The rapid deployment of AI-powered surveillance systems — encompassing real-time video analytics, facial recognition, and anomaly detection — raises acute data-security concerns, especially as quantum computing threatens legacy encryption standards such as RSA and AES. This research proposes, formally analyses, and fully implements a Secure AI-Surveillance framework that couples a deep convolutional neural network (ResNet-50) for visual intelligence with a post-quantum Learning With Errors (LWE) encryption layer for data confidentiality.

We formally prove that the LWE encryption wrapper achieves IND-CPA security under the standard LWE assumption, provide tightness bounds on the decryption-error probability, and show that the computational overhead of the cryptographic layer is linear in the feature-vector dimension — making it practical for real-time pipelines.

§ 01

Research Proposal

Background & Motivation

Modern surveillance infrastructure increasingly depends on deep neural networks to automate detection of threats, crowd behaviour, and individual identities. Video frames and extracted feature vectors traverse insecure channels and are stored in cloud databases, making them attractive targets. Current protection relies on AES-256 for symmetric encryption and RSA/ECDH for key exchange — both vulnerable to Shor's quantum algorithm running on a fault-tolerant quantum computer with ≈4096 logical qubits.

The U.S. National Institute of Standards and Technology (NIST) finalised its first batch of post-quantum standards in 2024 (FIPS 203 / CRYSTALS-Kyber, FIPS 204 / Dilithium), both rooted in the Learning With Errors (LWE) problem.

Problem Statement

Given a surveillance pipeline that produces a sequence of neural feature vectors f ∈ ℝ^d (d ≈ 2048 for ResNet-50), design and prove secure a post-quantum encryption scheme E such that:

  • E(f) is computationally indistinguishable from uniform under the LWE hardness assumption.
  • Dec(sk, E(f)) = f exactly for chosen parameters, or with negligible error probability.
  • The total latency of Enc + Dec is below 50 ms per frame on commodity hardware.
  • The scheme degrades gracefully — an adversary with a quantum computer gains no advantage beyond brute-force lattice reduction.

Research Objectives

  • Develop a modular ResNet-50 surveillance backbone trained on CIFAR-10 as a proxy dataset.
  • Design an LWE-based encryption layer operating on quantised neural feature vectors.
  • Formally prove IND-CPA security and characterise decryption-error probability.
  • Implement the full pipeline end-to-end in Python (TensorFlow + NumPy).
  • Benchmark throughput, memory footprint, and classification accuracy under encryption.

Significance & Novelty

Existing post-quantum proposals encrypt short keys or messages. This scheme targets high-dimensional feature vectors (2048 floats) and provides a rigorous error-probability bound that scales with vector dimension — a gap in the current literature. Integration with a production-grade CNN backbone provides the first openly published end-to-end secure AI-surveillance prototype with formal post-quantum guarantees.

§ 02

Background & Literature Review

AI-Based Surveillance

Convolutional Neural Networks, particularly deep residual networks (He et al., 2016), have become the de-facto backbone for image classification and object detection. ResNet-50, with its 50 layers and skip connections, achieves top-1 accuracy of 76% on ImageNet. The model extracts a 2048-dimensional feature vector at its penultimate layer — this vector encodes the semantic content of an image and is the target of the encryption.

Threat Model for AI Surveillance Data

A passive network adversary (Eve) observes encrypted feature vectors in transit; a curious storage provider holds ciphertext databases; and a future quantum-capable adversary may run Shor's algorithm after recording today's ciphertext. The goal is harvest-now-decrypt-later resistance — ciphertexts recorded today must remain secure even against a quantum computer built in 10–15 years.

Classical Encryption Shortcomings

RSA-2048 security reduces to integer factorisation, which Shor's algorithm solves in polynomial quantum time. ECDH over P-256 similarly falls to the quantum discrete logarithm. AES-256 is weakened from 2256 to 2128 effective security by Grover's algorithm — still acceptable, but key-exchange remains broken.

Post-Quantum Cryptography (PQC)

The NIST PQC standardisation process (2016–2024) produced four standards. CRYSTALS-Kyber (now ML-KEM, FIPS 203) is an IND-CCA2 key encapsulation mechanism built on Module-LWE. CRYSTALS-Dilithium (now ML-DSA, FIPS 204) is a signature scheme. Both derive security from the LWE problem, first formalised by Oded Regev in 2005.

Learning With Errors — Informal Overview

The LWE problem asks: given many approximate linear equations over a finite field (with small random errors), recover the hidden secret. Formally:

Given (A, b) where A ← Z_q^{m×n} uniformly b = As + e mod q with s ← Z_q^n and e ← χ^m (small error) Distinguish (A, b) from (A, u) with u ← Z_q^m uniform.

Regev proved that solving LWE is at least as hard as approximating worst-case lattice problems (GapSVP, SIVP) to within polynomial factors — problems for which no quantum algorithm is known.

Mathematical Foundations

Lattices

A lattice Λ ⊂ ℝn is the set of all integer linear combinations of a basis B = {b₁, …, bₙ}: Λ(B) = {Bz : z ∈ ℤn}. Key computational problems:

  • Shortest Vector Problem (SVP): Find the shortest non-zero vector λ₁(Λ).
  • Closest Vector Problem (CVP): Given target t, find the lattice vector closest to t.
  • GapSVPγ: Approximate SVP to within factor γ(n) — believed hard even for quantum computers for γ = poly(n).

Discrete Gaussian Distribution

The discrete Gaussian Dℤ,σ assigns probability proportional to exp(−x²/2σ²) over ℤ. For LWE we use χ = Dℤ,σ truncated to ensure failure probability δ. A common parameter is σ = q/(2π√n) ensuring (statistical) security.

The LWE Problem — Formal Definition

Definition 3.1 — LWEn,q,χ

Let n, m, q ∈ ℤ₊ with q prime, and let χ be a distribution over ℤq. The LWE distribution As,χ for s ∈ ℤqn samples (a, ⟨a,s⟩ + e) with a ← ℤqn and e ← χ.

Search-LWE: Given m samples from As,χ, recover s.

Decision-LWE: Distinguish m samples from As,χ from m uniform samples over ℤqn × ℤq.

LWE Encryption Scheme Π

Key Generation

Parameters: n (dimension), q (prime modulus), m = O(n log q) (samples), χ (error distribution).
Sample A ← ℤqm×n uniformly; s ← ℤqn; e ← χm.
Compute b = As + e mod q.
Public key: pk = (A, b)    Secret key: sk = s

Encryption — single bit μ ∈ {0,1}

Sample r ← {0,1}m. Compute u = ATr mod q ∈ ℤqn and v = bTr + ⌊q/2⌋·μ mod q ∈ ℤq.
Ciphertext: ct = (u, v)

Decryption

Compute w = v − uTs mod q.
If w is closer to 0 than to ⌊q/2⌋ (mod q), output μ = 0; otherwise output μ = 1.

Extension to Feature Vectors

A ResNet-50 feature vector f ∈ ℝd (d = 2048) must be quantised and encrypted component-by-component:

  • Quantise: f̂ᵢ = round(fᵢ · S) mod q for scale factor S = q/8.
  • For each component: convert f̂ᵢ to ⌈log₂q⌉-bit binary and encrypt each bit with Π.
  • Ciphertext: CT = {ctᵢⱼ} for i ∈ {1,…,d}, j ∈ {1,…,⌈log₂q⌉}.

Total ciphertext expansion for d=2048, q=215, n=256: ≈ 237 MB per feature vector (acceptable for batch secure storage; live streaming uses Ring-LWE variants to reduce this by ≈1000×).

Rigorous Security Proofs

IND-CPA Security

Theorem 5.1 — IND-CPA Security under Decision-LWE assumption

The scheme Π = (KeyGen, Enc, Dec) is IND-CPA secure under the Decision-LWEn,q,χ assumption. For any PPT adversary 𝒜 playing the IND-CPA game, there exists a PPT distinguisher 𝒟 against Decision-LWE such that:

Adv^{IND-CPA}(𝒜) ≤ 2 · Adv^{LWE}_{n,q,χ}(𝒟)

Proof sketch (hybrid argument):

G₀ (real game): 𝒜 receives pk = (A, b) where b = As + e, chooses plaintexts μ₀, μ₁, receives ct* = (ATr, bTr + ⌊q/2⌋·μβ) and outputs β'.

G₁: Replace b with uniform b' ← Zqm. Transition from G₀ → G₁ is computationally indistinguishable by Decision-LWE.

G₂: In G₁, ciphertext becomes (ATr, b'Tr + ⌊q/2⌋·μβ). Since b'Tr is uniform, v* is uniform regardless of μβ — 𝒜 has zero advantage. □

Correctness & Decryption Error Probability

Theorem 5.2 — Correctness via Hoeffding's inequality

For a single-bit encryption, the decryption error probability satisfies:

Pr[Dec(sk, Enc(pk, μ)) ≠ μ] ≤ 2 · exp(−q²/(32m·σ²))

Decryption computes w = eTr + ⌊q/2⌋·μ. Error occurs iff |eTr| > q/4. By Hoeffding's inequality for sub-Gaussian variables (each rᵢeᵢ with parameter σ²):

Pr[|e^T r| ≥ t] ≤ 2·exp(−t²/(2mσ²)) Setting t = q/4: Pr[error] ≤ 2·exp(−q²/(32mσ²))

For our parameters (q=7681, m=1024, σ=3.19):

2·exp(−7681²/(32·1024·3.19²)) ≈ 2·exp(−7.0×10⁶) ≈ 10^{−3×10⁶} □

Post-Quantum Security

Theorem 5.4 — Post-Quantum Security BKZ lattice reduction

The best known quantum algorithm for Decision-LWE256,7681,χ runs in time Ω(272), providing 72-bit quantum security.

The BKZ block size β required to break LWE satisfies the core-SVP hardness estimate:

log₂(security) ≥ 0.292β − 16.4 → β ≈ 305 → 72 bits quantum security

No quantum algorithm exceeds quadratic speedup for lattice reduction (unlike Grover's O(√N) for unstructured search), so quantum security is approximately half the classical: 144/2 = 72 bits. □

§ 07

Challenges & Future Work

Current Challenges

  • Ciphertext Expansion. Naive LWE expands a d-dimensional vector by O(d·log(q)·(n+1)). Solution: Ring-LWE reduces this to O(log q) expansion per component using polynomial arithmetic in ℤq[x]/(xn+1).
  • Computational Latency. Python-level LWE is too slow for real-time (25 fps) encryption. Solution: Implement NTT-based polynomial multiplication in C/CUDA; target <10 ms per feature vector.
  • Side-Channel Resistance. The Gaussian error sampler and matrix-vector products may leak timing information. Mitigation: constant-time algorithms, hardware RNG, and masking from NIST PQC guidelines.
  • Key Management. Securely distributing and rotating LWE key pairs at scale requires a post-quantum key infrastructure — an open research problem.

Future Research Directions

  • Ring-LWE Variant: Replace plain LWE with Module-LWE (Kyber) to reduce ciphertext size by ~1000× and latency by ~500×. Integrate with TensorFlow Lite for edge-device deployment.
  • Homomorphic Inference: Use FHE (TFHE or CKKS) to run the classifier head directly on encrypted features — eliminating server-side decryption.
  • Formal Verification: Use ProVerif or Tamarin Prover to machine-verify the IND-CPA proof, closing the gap between paper proof and implementation.
  • Hardware Acceleration: Implement the NTT core on FPGA (e.g., Xilinx Zynq) to achieve <1 ms encryption per feature vector, enabling real-time 4K surveillance.
  • Federated Learning Integration: Combine LWE encryption with federated learning so surveillance nodes train a shared model without sharing plaintext activations.
  • Post-Quantum TLS: Replace interim TLS 1.3 with Kyber + Dilithium based TLS, completing a fully post-quantum pipeline.
