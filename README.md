# Secure_AI_Surveillance

A clean, concise repository overview for the `secure_ai_surveillance` project.

## Overview

This repository includes a standalone HTML demonstration of a secure AI surveillance concept.

## What’s Included

- `index.html` — The GitHub Pages entrypoint. It redirects to the main page.
- `secure_ai_surveillance.html` — The main project page with the full presentation.

## Deployment

When deployed on GitHub Pages, the site root will serve `index.html`, which immediately forwards to `secure_ai_surveillance.html` so the main project page is displayed.

## Usage

1. Open `index.html` locally or visit the root of the deployed GitHub Pages site.
2. The browser will automatically redirect to `secure_ai_surveillance.html`.
3. If the redirect does not work, open `secure_ai_surveillance.html` directly.
