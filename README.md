# Secure_AI_Surveillance

A clean, concise repository overview for the `secure_ai_surveillance` project.

## Overview

This repository includes a standalone HTML demonstration of a secure AI surveillance concept.

## What’s Included

- `index.html` — The GitHub Pages entrypoint. It redirects to the main page.
- `secure_ai_surveillance.html` — The main project page with the full presentation.

## Deployment

**Live site:** [https://syedayasmeen22.github.io/AI-Surveillance-/](https://syedayasmeen22.github.io/AI-Surveillance-/)

GitHub Pages is configured to publish the `main` branch from the repository root. The root `index.html` forwards to `secure_ai_surveillance.html`, where the main project page is displayed. The repository website link above points to the deployed site.

## Usage

1. Visit the [live GitHub Pages site](https://syedayasmeen22.github.io/AI-Surveillance-/), or open `index.html` locally.
2. The browser forwards to `secure_ai_surveillance.html`.
3. If the redirect does not run in a local preview, open `secure_ai_surveillance.html` directly.
